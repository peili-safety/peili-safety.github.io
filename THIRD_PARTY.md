# Third-party template and assets

Blotter: https://github.com/blab/blotter
Imported from commit 16d1dcd6d2da10780a282bbe52995969f76bac5e (2026-09-06).
The layouts and page markup are adapted; `_blotter/custom.scss`, Bootstrap,
Font Awesome, Solarized, and Bootstrap JavaScript are vendored from this version.
`_blotter/_lab.scss` contains local refinements. Bedford Lab content, logo,
Adobe Typekit account, and analytics configuration are not included.
